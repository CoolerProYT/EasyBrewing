# Getting started

These pages cover Easy Brewing for **Minecraft 1.20.1 to 26.2**. For Minecraft 26.3, use the version menu at the top of the page.

Easy Brewing adds the Item Brewing Station, a brewing stand that brews from a whole stack of potions and can be upgraded to brew faster and in bigger batches. The station, its upgrades and its recipes are the same in every version. What changes is how brewing recipes are added and which other mods it works with.

## Install

1. Install a mod loader for your Minecraft version:

   | Minecraft | Loaders |
   | --- | --- |
   | 1.20.1 | Forge, Fabric |
   | 1.21.1 | NeoForge, Fabric |
   | 1.21.11 | NeoForge, Fabric, Forge |
   | 26.1, 26.2 | NeoForge, Fabric |

   On Fabric, also install Fabric API.
2. Put the Easy Brewing jar for your Minecraft version and loader in your `mods` folder.
3. Optional: add JEI or REI to look up brewing recipes from the station. [Other mods](./compat) lists which ones your version supports.
